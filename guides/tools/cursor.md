# Cursor

Host id: `cursor`.

Install as in [INSTALL.md](../../INSTALL.md). A `cursor` program on `PATH` does not select this host. Name it with `--hosts cursor` or `CHAOS_ENGINE_HOST=cursor`.

Cursor is instruction-only. It reads `AGENTS.md`. Completing this host writes `.cursor/hooks.json`. There is no portable pre-tool hook (GAP-CURSOR-HOOKS). The research receipt replaces that gate.

Published context and instruction caps are `unknown`. See [capability profiles](../../references/profiles/capabilities.md).

Example, not yet validated by the offline conformance job: install into a repository of stories, then follow [the developer start](../start-developer.md). No Java is required.
